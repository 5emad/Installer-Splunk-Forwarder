# Splunk UF Deployer

وب‌اپ (Flask) برای نصب و مدیریت Splunk Universal Forwarder، Sysmon و auditd روی تعداد زیادی سرور ویندوز و لینوکس، و تنظیم syslog روی تجهیزات Cisco.

## اجرا (Python 3.10+)
```
pip install -r requirements.txt
python app.py               # http://127.0.0.1:5000  (مرورگر خودکار باز می‌شود)
python app.py 8080          # پورت دلخواه
python app.py --no-browser  # بدون باز کردن مرورگر
```
- `start.bat`: اجرا در پس‌زمینه. `install_autostart.bat`: اجرای خودکار بعد از لاگین (با دسترسی Administrator).
- `build_exe.bat`: ساخت `dist\UFDeployer.exe`. پوشه‌ی `data\` کنار خود exe ساخته می‌شود.

## پیش‌نیازها
- **ویندوزِ هدف:** WinRM فعال (`winrm quickconfig`) و کاربر Administrator. اگر WinRM در دسترس نباشد، از SMB (`C$`) و Scheduled Task استفاده می‌شود؛ این حالت فقط وقتی کار می‌کند که خود برنامه روی ویندوز اجرا شود.
- سرورهای ویندوزی فایل‌ها را از «Tool address» دانلود می‌کنند؛ پس پورت برنامه (پیش‌فرض 5000) باید در فایروال این سیستم باز باشد. اگر UI را با `localhost` باز کرده باشید، برنامه خودش IP این سیستم را جایگزین می‌کند.
- برای حساب‌های محلی (غیر دامنه) روی ویندوزِ هدف، ممکن است `LocalAccountTokenFilterPolicy=1` لازم باشد.
- **لینوکسِ هدف:** SSH و کاربری که عضو sudoers باشد (رمز از طریق stdin به `sudo -S` داده می‌شود و در خط فرمان دیده نمی‌شود). فایل‌ها با SFTP فرستاده می‌شوند.
- **Cisco:** SSH یا Telnet.

## فرمت اهداف
```
10.0.0.5
10.0.1.0/24
10.0.2.10-10.0.2.40
10.0.3.7,DOMAIN\admin,Password      (اعتبارنامه‌ی همین خط)
10.0.4.0/24 @servers                (پروفایل اعتبارنامه)
lin:10.0.5.9,ubuntu,pass            (تعیین سیستم‌عامل برای همین خط)
```
حداکثر ۴۰۹۶ هدف در هر اجرا. آدرس‌های تکراری حذف می‌شوند.

## نکات
- فایل‌ها (UF، Sysmon، conf، rules، app) یک بار در «Files library» آپلود می‌شوند و در پوشه‌ی `data\` می‌مانند.
- تاریخچه در `data\history.db` (SQLite) است. از تب «History & Reports» می‌توانید خروجی CSV، گزارش فنی و گزارش مدیریتی (فارسی یا انگلیسی) بگیرید.
- رمزها فقط در حافظه‌ی همان اجرا نگه‌داری می‌شوند و در تاریخچه ثبت نمی‌شوند.
- بعد از Push conf یا Deploy app، سرویس Splunk را Restart کنید.

## امنیت
- برنامه روی همه‌ی کارت‌های شبکه (`0.0.0.0`) گوش می‌دهد، چون سرورهای ویندوزی باید فایل‌ها را از آن دانلود کنند، و **احراز هویت ندارد**. فقط در شبکه‌ی مدیریتیِ مورد اعتماد اجرا کنید.
- مسیر `/files/` فقط فایل‌های کتابخانه را می‌دهد؛ `history.db`، گروه‌ها و branding از شبکه قابل دانلود نیستند.
- پوشه‌ی `data\` (آدرس‌های داخلی، فایل‌های نصب، Sysmon.exe) در `.gitignore` است. آن را commit یا منتشر نکنید.
