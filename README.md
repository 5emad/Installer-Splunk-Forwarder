# UF Deployer

وب‌اپ محلی (FastAPI + UI فارسی) برای استقرار و مدیریت Splunk UF، Sysmon، auditpol و auditd.

## اجرا (روی ویندوز، Python 3.10+)
    pip install -r requirements.txt
    python app.py          # http://127.0.0.1:8000  (فقط لوکال)

## پیش‌نیازها
- **ویندوزِ هدف:** WinRM فعال (`winrm quickconfig`)، و اشتراک ادمینی `C$` در دسترس (برای کپی فایل‌ها با SMB از ویندوزِ مبدا). کاربر باید Administrator باشد.
- **لینوکسِ هدف:** SSH و کاربر عضو sudoers (رمز با `sudo -S` ارسال می‌شود).
- فونت‌ها از Google Fonts لود می‌شوند؛ برای شبکه ایزوله Vazirmatn/Inter را محلی کنید.

## نکات
- تاریخچه در `history.db` (SQLite) ذخیره می‌شود؛ خروجی CSV و PDF از تب «تاریخچه».
- PDF با فونت پیش‌فرض ساخته می‌شود و متن فارسی را شکل‌دهی نمی‌کند (ستون‌ها انگلیسی‌اند).
- رمزها فقط در حافظه‌ی همان درخواست نگه‌داری می‌شوند و در تاریخچه ثبت نمی‌شوند.
- فقط دستورات ساده‌ی `auditpol` پذیرفته می‌شوند (بدون `; | & $ ( )` و ...).

## امنیت
- هر اجرای برنامه یک توکن تصادفی می‌سازد. همه‌ی درخواست‌های `/api` باید کوکی آن را داشته باشند و درخواست‌های تغییردهنده هدر `X-UFD-Token` را هم. پس سایت‌های دیگر نمی‌توانند از داخل مرورگر عملیاتی اجرا کنند. بعد از ری‌استارت برنامه، صفحه را رفرش کنید.
- کلید SSH هاست‌ها (لینوکس و Cisco) بار اول در `known_hosts` کنار `history.db` ذخیره می‌شود. اگر بعداً کلید عوض شود، اتصال رد می‌شود. اگر هاست واقعاً دوباره نصب شده، خط آن هاست را از این فایل پاک کنید.
- احراز هویت Basic در WinRM فقط روی HTTPS (5986) مجاز است.
- در «دستورات اضافه»ی Cisco فقط دستورات لاگینگ (logging، service timestamps، archive/log config، login، ntp، clock) مجازند.
- `history.db` آدرس‌های داخلی شبکه را دارد. موقع اشتراک‌گذاری پروژه آن را همراهش نفرستید.
